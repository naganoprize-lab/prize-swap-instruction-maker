# プライズ景品 入替指示書メーカー

ゲームセンターの入荷Excelから日付別の商品を抽出し、マシン番号・運営方法などを設定して、左右2ブロックの入替指示書を出力する日本語Windowsデスクトップアプリです。

## Windowsで使う（Python不要）

1. GitHubの **Actions → Windows portable EXE** で成功した実行を開きます。
2. **Artifacts → PrizeSwapInstructionMaker-windows-x64** をダウンロードして展開します。中のZIPも展開してください。
3. `PrizeSwapInstructionMaker.exe` を起動します。インストールは不要です。
4. **Excelを開く** で `.xlsx` または `.xlsm` を選びます。
5. カレンダーまたは登録日一覧から日付を選びます。青い日付は商品がある日です。該当商品がない日は0件表示になります。
6. 商品一覧のセルをクリックして、商品名・入数・CS数・順序・マシン番号を直接編集します。Enterまたは別のセルへの移動で確定します。
7. 運営方法セルのドロップダウンで、商品ごとの **予定ブース数** と **マシン別の運営方法** を設定します。個数制限はセル内プルダウンで選択します。
8. 上部の **印刷プレビュー** で確認し、**直接印刷** または **PDF保存** を実行します。Excelファイルが必要なときは下部の **Excel出力** を使います。

ライト・ダーク・システム連動を選べる、ブルーをアクセントにしたUIです。初期設定はシステム連動で、Windowsのアプリ用ダークモードに追随します。右上のテーマメニュー、または左の「設定」から即時切替でき、再起動後も復元します。商品一覧が画面中央を使用し、右側の一括編集パネルはありません。行高34px、フォント約10pt、交互背景色・選択行ハイライトに対応します。列境界をドラッグして幅を変えられ、横スクロールと商品名のツールチップも使えます。

検索は商品名・メーカー・マシン番号・運営方法に対応します。「全選択」「全解除」は**検索・絞り込みで表示中の商品の出力チェック**を変更します。Ctrl/Shiftで行を複数選択し、「↑ 上へ」「↓ 下へ」で並び替えできます（検索・絞り込みは解除してください）。順序の数値を直接編集しても並びが変わります。同順位は元の順序を保ちます。

印刷・PDF・Excel出力は、検索に関係なく**選択日の出力チェックが入っている商品すべて**が対象です。日付を変えても編集内容を保持します。

マシン番号は `20085右,20098左` のように入力できます。セル内の複数行入力・貼り付けにも対応し、右端の「▾」から売り場レイアウトに登録済みの番号を追加・解除できます。カンマ、全角カンマ、読点、改行、セミコロンで区切れます。同じ番号は1件として扱います。

### 予定ブース数とマシン別の運営方法

運営方法セルの **予定ブース数・商品集計** で、標準の **橋渡し・リング・フック** の予定数を0以上の整数で入力します。マシン番号が未登録でも入力できます。0は予定なし、1以上は選択状態です。**自由記載** に運営方法名を入力して「追加」を押すと、独自の方法にも予定数とマシン別の割当を設定できます。旧方式の直置き・吊り下げ・たこ焼き・その他は標準から外れますが、保存済みの値は自由記載としてそのまま保持します。Tab・矢印キー・マウスで操作でき、別のダイアログは開きません。

同じセルの **マシン別の運営方法** タブでは、登録した各マシンに方法を指定します。例えば `20098右→橋渡し、20083左→リング、20103右→橋渡し` の場合、一覧は実際の割当を **橋渡し×2、リング×1** と表示し、割当済み・未割当・超過の状況も併記します。予定数はこの実績とは別に保存します。リング予定3ブース、リングのマシン1台であれば、予定は3のままで未割当2と表示・印刷します。

一覧下部の **ブース予定集計** を開くと、選択日の出力対象すべて、または選択中の商品について、方法別の予定・割当・未割当・超過を確認できます。商品間の不足と超過は相殺しません。商品別の詳細はセルのツールチップとドロップダウンでも確認できます。方式別の行と合計行は、割当済み＝薄い緑＋濃い緑、未割当＝薄いオレンジ＋濃いオレンジ、超過＝薄い赤＋濃い赤で表示し、数字と見出しを併記します。予定超過の割当は出力前に確認します。

未割当は `max(予定数−実際の方法割当数, 0)`、超過は `max(実際の方法割当数−予定数, 0)` です。番号だけ登録したマシンや方法が空白のマシンは割当済みに含めず、重複番号も二重計上しません。予定未設定の差分は「未設定」と表示し、0とは区別します。

マシン番号を削除すると、その番号の方法は退避して集計から外します。同じ番号を戻すと元の方法も復元します。番号を変更した場合は別のマシンとして未設定から選び直します。予定数と既存の割当を推測で書き換えません。旧JSONの方法名だけの設定は保持し、予定数とマシン別の対応は未設定として表示します。

優先入替の商品は表・印刷の該当商品ブロックを薄いピンクにします。印刷とExcelでは商品名に「【優先入替】」も付けます。個数制限は「制限なし」「各①〜各⑩」「トータル①〜トータル⑩」をそのまま出力します。

## 直接印刷・プレビュー・PDF

PySide6の `QPrinter`・`QPrintDialog`・`QPrintPreviewDialog`・`QPainter` を使用します。プレビュー・直接印刷・PDF保存は同じ寸法計算と描画を使用します。初期設定はA4横・余白6mm・自動最適化です。日本語フォントを埋め込んだ検索可能なPDF、黒い罫線、太字の商品名を維持します。

下部または印刷プレビューで **自動最適化／標準／コンパクト** を選択できます。プレビュー内で変更するとその場で再描画します。設定はJSONに保存し、旧JSONは自動最適化になります。

- **自動最適化**：10〜20商品は1ページ、21〜40商品は最大2ページを目標に、実測結果から読みやすい設定を選びます。商品名10〜13pt・本文9〜10ptの範囲で調整し、条件を満たす大きい文字を優先します。
- **標準**：商品名14pt・本文11pt。読みやすさを優先し、内容によってページ数が増えます。
- **コンパクト**：商品名10〜11pt・本文9pt。欠落や省略をせず、可読性の下限を保った候補から用紙を節約する設定を選びます。

商品名は `QTextLayout` と実際のフォントで折り返しを計測し、マシン行・運営方法・予定数・割当数・セル内余白を含む必要最小限の高さを確保します。`QFontMetricsF` で他の項目に必要な列幅を計測し、商品名に広い幅を割り当てます。商品名・入数・CS数・個数制限は商品単位の結合領域に1回だけ描画します。

左を上から下へ、次に右を上から下へ進む登録順を保ち、実測高を使って可能な分割位置をすべて評価します。左右を別々に積み上げ、合計高さの差が小さい分割を選びます。ページ数を最小化したうえで、左右とページ間の密度が均等になるように境界を計算します。「左右交互」の配置も引き続き選べます。

**片側上限** はPDF・直接印刷での最大商品数（1〜50）です。小さく設定するとページが増えます。長文や大量のマシンを省略せず配置すると目標を超える場合は、必要なページ数、実際の文字サイズ、最大行数・マシン行数・設定上限などの理由をプレビューに表示します。

運営方法の欄には、商品ごとの予定・割当済み・未割当・超過を色と数字で表示します。自動・コンパクトでは `橋渡し 2 済1 未1 超0` のように表示し、予定数の単位「ブース」は見出しに記載します。標準では `橋渡し 2ブース` と表示します。各商品に合計も記載し、凡例で **済＝割当済み／未＝未割当／超＝超過／?＝予定未設定** を説明するため、白黒印刷でも区別できます。予定数は実際のマシン数から書き換えません。

1商品だけで印刷可能な高さを超える場合に限り、マシン行の境界で継続ブロックに分けます。各継続ブロックにも商品名と予定数を表示し、ページに「継続商品あり」を記載します。商品名だけで1ページに収まらない極端な長文は、切り捨てず修正を促して出力を中止します。PDFは一時ファイルを経由して保存するため、失敗時は既存のPDFを保持します。上書きは保存ダイアログで確認します。

「直接印刷」はWindows標準のダイアログでプリンター、部数、ページ範囲などを指定します。プレビューと実印刷で同じ用紙・向き・余白を使ってください。プリンタードライバーの印刷可能領域や設定変更により改ページが変わる場合があります。**実プリンターからの用紙出力はWindows実機で確認が必要**です。

## 売り場レイアウトとマシン管理

「売り場レイアウト」タブ → **ファイル → レイアウトExcel読込** で `.xlsx` / `.xlsm` を選びます。商品用の「縦」シートがなくても、配置専用Excelとして読み込めます。

読み取り対象は `投入中レイアウト` シートの `L_66` / `R_66` のような参照IDセルです。その右隣のセルを現在の商品名として取得し、Excelの列幅・行高による位置関係をキャンバスに配置します。参照IDの下にある `売上/ｱﾍﾞﾚｰｼﾞ` の右2セルから売上・アベレージ、`PO率/ｱﾍﾞ比` の右隣からPO率、右2番目からアベ比、`設置日/設定2` の右隣から設置日を読みます（設定2は使用しません）。アベ比はExcelの値を優先し、パーセント書式の値は100倍します。未入力の場合だけ売上÷アベレージ×100で補います。アベレージ0・未取得の数値や日付は「—」です。図形ベースのレイアウトや任意の別書式の自動解釈には対応しません。

`管理番号参考値` シートのA列=管理ナンバー、B列=機械番号を使います。「管理ナンバー参考表」等も、管理番号・機械番号のヘッダー名を優先して認識します。ヘッダーのない既存の2列形式も読み込めます。提供された `レイアウト_参照値.xlsm` は298枠に対して対応表が6件です。機械番号が不明な枠は管理ナンバーを表示し、`L_66` を `66左` などと推測しません。同じ管理ナンバーに異なる番号がある場合、1番号に複数の管理ナンバーがある場合、左右不明、直接番号と参考表の矛盾は「照合要確認」にして実績を割り当てません。カードをクリックして詳細を開き、「番号・稼働値を編集」で実番号を登録してください。配置編集時はダブルクリックまたは「詳細」ボタンで開きます。

- **マシン追加**：番号、左右、種別、現在の商品を設定して配置。登録済みの番号と左右の組み合わせの重複を拒否します。
- **移動・サイズ**：「実配置」で「配置編集」をオンにしてドラッグで移動、選択した枠の四隅でサイズ変更。Ctrl+クリックで複数選択し、一括移動できます。背景の範囲選択にも対応します。
- **複製**：Ctrl+Dまたは「複製」。少しずらして配置し、番号は未設定になります。「詳細 → 番号・稼働値を編集」で新番号を確定してください。
- **削除**：Deleteまたは「削除」。複数枠をまとめて削除できます。確認ダイアログを出し、入替予定で使用中ならその中で警告します。
- **整列**：左揃え、上揃え、横・縦の等間隔に対応。等間隔は3枠以上で行い、両端の間に枠が収まらない場合は警告します。
- **元に戻す／やり直し**：Ctrl+Z / Ctrl+Y。追加、削除、複製、移動、サイズ変更、整列、番号変更、配置の読み込み・リセットが対象です。
- **表示**：倍率50〜300%、＋／−、倍率入力、「全体」「選択へ」を使えます。ホイール・Ctrl＋ホイールの両方で拡大縮小します。閲覧時は背景のドラッグで画面移動、配置編集時は中ボタンまたはSpace＋ドラッグで画面移動します。全体表示だけは、大きい売り場を収めるため50%未満になる場合があります。
- **カード・文字サイズ**：選択したマシンまたは全マシンの幅・高さと基準文字サイズを別々に変更します。文字だけの変更は位置・カード寸法を変えません。商品名は太字で自動折り返しし、収まる範囲へ文字を調整します。全情報はツールチップでも確認できます。カードが重なる場合は台数と赤い枠で警告し、手動で配置を調整できます。

背景はアベ比200%以上＝黄色 `#FFE16A`、100%以上200%未満＝緑 `#94D8A0`、50%以上100%未満＝白 `#FFFFFF`、50%未満＝赤 `#F4A6A6` です。50.0%は白、49.9%は赤です。未取得はグレー `#B8BEC6`、数値は「—」です。分析フィルターでは選択した指標を背景色に使用し、投入予定は青い小マーカーと文字、優先入替は黄色い枠で示します。「投入予定地」フィルターでは予定のある枠の背景を青 `#A9D7FF` にします。画面・印刷プレビュー・PDF・直接印刷で同じ判定を使い、数値と状態の文字も併記します。削除・番号変更で入替予定は自動的に消去・変更しません。元の予定が残ることを警告し、商品一覧で正しいマシンへ修正できます。配置に存在しない番号が印刷・PDF対象にある場合にも確認を表示します。

通常カードは色フィルターに応じた **3項目** です。初期値の「アベ比」はマシン番号・大きい太字のアベ比・商品名を表示し、設置日数は表示しません。「投入予定地」は予定のある枠だけ青、他は白にし、アベ比の背景色を無効にします。「設置日数」はマシン番号・大きい太字の設置日数・商品名を表示し、10日以上を紫 `#C5A5ED`、9日以下・未来を白、不明をグレーにします。このモードでは予定の青やアベ比の背景色を適用しません。基準日より未来は「投入予定」、不明は「—」です。長い商品名は最大3行へ省略します。全文はクリックして詳細で確認できます。売上・アベレージ・PO率・設置日・メーカー・入数・CS数・個数制限・運営方法は詳細画面に表示します。未取得は「—」です。名前の一致だけで他の商品から情報を補完しません。

詳細の「現在投入中の商品」と「選択日の入替予定」は別タブです。現在商品・現在の運営方法を編集でき、入替予定タブでは既存の商品情報・マシン別運営方法・予定ブース数を直接編集します。予定数を重複保存しません。Saveで確定、Cancelでは変更しません。Ctrl＋Z／Yで詳細変更も戻せます（後から商品一覧で変更した競合項目は保持して通知）。

表示配置は **実配置**（Excelの座標、配置編集可）、**見やすさ優先**（相対位置を保って画面上のカードを拡大）、**一覧**（カードを自動整列）の3種類です。後者2つで実際のマシン座標・サイズは変わりません。一覧は「表示設定 → 一覧の並び順」でマシン番号・アベ比・投入日数・商品名の昇順／降順に並べ替えます。上部で50%未満／200%以上／投入予定、投入日数の範囲、番号・商品名・機種・運営方法を検索できます。検索や「強調条件」は全マシンの配置を保ち、一致だけをシアン枠、不一致を減光します。0件でも消えません。「前へ」「次へ」で一致箇所へ移動できます。検索解除時は元の倍率・位置へ戻ります。未取得の比率・日数は数値条件に含めません。凡例はチェックで表示・非表示にできます。

**全画面** は売り場タブを明示的に再表示し、サイズ確定後に倍率・位置を復元します。上部は色フィルター、検索、前へ／次へ、＋／−、全体、詳細、配置編集、概要、解除にまとめ、Escで元のタブへ戻ります。選択・詳細・配置編集を全画面でも使えます。保存・実績読込・印刷はキャンバスの右クリックメニューから利用できます。倍率と表示位置を保存・復元します。Excelを新規読込した直後は100%で先頭のカード付近を表示し、300台全体への極端な自動縮小を避けます。全体図は「全体」で確認できます。「表示設定」からカード寸法・文字サイズ、プリセット保存／適用を操作できます。実配置でプリセットを適用すると選択マシン（未選択なら全台）のサイズだけを変更し、座標は保持します。見やすさ優先／一覧では表示サイズだけを変えます。従来の詳細表示項目と運営方法の表示切替も「表示設定」に残しています。旧JSONを初めて読み込む場合の通常表示はアベ比フィルターの3項目になります。

**基準日** は初期値がPCの今日です。投入日数＝基準日−設置日で、同日は0日、未来なら「投入予定」、不明なら「—」です。「今日に戻す」後は日付の切替にも追随します。任意の日付を選ぶと固定します。基準日を変えても売上等は現在読み込んだ値のままで、過去の値へ推測・変更しません。読込日時とその旨を画面・印刷に表示します。

**運営方法を表示** をオンにすると、選択日の入替予定に登録されたマシン別の方法を表示します。ツールチップからも確認できます。

**保存** は配置専用JSON、下部の **一時保存** は商品データと配置を含むJSONです。位置・サイズ・追加削除・番号・種別・商品名・稼働データ・文字サイズ・元の配置・表示モード・絞り込み・並べ替え・カードプリセット・基準日・表示倍率・表示位置・印刷設定を保存します。旧JSONは欠けた新項目を初期値で補います。配置は編集後約0.8秒で自動保存され、再起動時に復元します。通常のWindows実行では `%LOCALAPPDATA%/PrizeSwapInstructionMaker/floor-autosave.json` に保存します。自動保存に失敗した場合はステータスに表示します。Undo履歴と選択状態は再起動後には復元しません。

Excel再読込時は、現在の編集済み配置を保持するかExcel配置へ置き換えるか選択できます。保持した場合は位置・サイズ・追加マシンを維持し、参照IDまたは番号が一意に一致するカードの商品・稼働データと「元の配置」を更新します。**元のExcel配置へ戻す** で最後に読み込んだ配置へ戻せます。どの操作でもExcelは読み取り専用で、元ファイルへ書き戻しません。

**用紙・印刷設定** でA4/A3/A2/A1/A0/ユーザー指定、縦・横、全体1枚／エリア別分割／マシン一覧表／指定倍率分割（従来の選択範囲も維持）を選べます。印刷文字（標準・大・特大）、印刷カード（自動・標準・拡大）、項目、カラー／白黒は画面とは独立しています。画面のズーム・スクロール・表示モード・カード寸法・文字サイズは印刷に影響しません。印刷カードの幅・高さは印刷設定で指定します。自動は必要な文字の高さまでカードを広げます。各カードの座標と相対位置は保持し、重なりや最小文字が8pt未満になる場合はプレビューで警告します。1枚に縮小して読みにくい場合は、A3・複数ページ分割・項目の削減を選んでください。画面とは独立した「印刷用の色フィルター」でアベ比／投入予定地／設置日数／PO率／原価率／売上／機種／入替候補を選びます。通常カードはフィルターに応じた3項目を表示し、アベ比または設置日数を大きくし、印刷では商品名を省略せず全文を出します。一覧表は番号／アベ比（または設置日数）／商品名の3列を用紙幅へ自動調整し、名前の実測高さに応じて行高と改ページを計算します。「画面の検索・強調一致だけを印刷」をオンにした場合だけ、画面の検索条件を印刷へ適用します。

印刷プレビュー内で設定を変えると即時更新します。PDF保存・直接印刷も同じ計測・描画を使います。分割ではカードが切れないようページ範囲を一部重ね、各カードは丸ごと1ページに1回だけ出力します。画面の破線はページ境界で、印刷にもページ番号と範囲を表示します。100%は96dpi画面のカード寸法相当で、実際の筐体の寸法ではありません。余白は6mmを基本にプリンターの印刷可能領域へ合わせます。対応外の用紙、プレビューと異なる用紙・向きは警告して中止します。

上部共通の印刷ボタンは選択中のタブを印刷します。売り場タブには専用のプレビュー・PDF保存・直接印刷ボタンもあります。実プリンターの給紙・色・余白はWindows実機で確認してください。

## 売上分析Excelの取込と優先順位

売り場タブの **売上分析Excel読込** から「景品運営分析表」のあるExcelを開きます。1行目のヘッダー名を優先し、標準ではB=機器番号、C=機器名、E=参考商品名、F=売上金額、G=稼働日数、H=平均売上、I=粗利益、J=原価率、K=P/O率、L=払出数、M=個当たり、O=景品単価、P=原価を検証・読込します。Nの景品種別は保存・表示しません。検索条件・日時など正規機器番号でない付随行は実績に含めません。F（売上金額）は数値必須です。G/Hの欠損は警告して保持し、売上が有効な行を除外しません。照合済みの最新分析で項目が欠損している場合は、その分析値を「—」にします。マシン自体が照合できない場合は、レイアウト内の有効な実績を「レイアウト由来」として表示します。古い分析ファイルの値を最新値として黙って補いません。不正数値行は除外して結果へ表示します。

機器番号は前後の空白を除き、`20088-01`→`20088左`、`20088-02`→`20088右` として完全一致で照合します。参照IDから実番号を推測しません。**分析 → 実績読込結果・異常一覧** で実績件数・照合更新件数・未照合一覧・数値エラー・JSTの最終読込日時を確認できます。番号未登録の枠は実番号を登録すると自動的に照合し直します。

表示・PDF・印刷では **安全に照合できた最新分析表** を優先します。未照合・要確認ならレイアウト内の有効な値を使い、数値の取得元とマシンの照合状態を分けて表示します。現在の商品名・設置日・配置・予定商品・運営方法は上書きしません。「売上登録用」は参考情報だけとして扱います。各新規読込は分析スナップショットを置き換え、最新ファイルにない番号にはレイアウト由来の有効な実績を表示し、両方にない指標だけを「—」にします。前の分析ファイルの値を最新値として残しません。同一ファイルの再読込や同一実績の重複行を加算しません。同一番号に異なる実績が重複する場合は推測して合算せず、照合から除外してエラー一覧へ表示します。

分析取込時のアベ比は **H列の平均売上 ÷ 既存の基準アベレージ ×100** です。基準は元のレイアウトの平均売上と既存アベ比から数学的に復元し、既存基準が複数台で一致すると確認できた場合のみ、比率0などで復元できない枠にも同じ基準を使用します。基準が不明な場合は新しい平均や日数から推測して計算しません。レイアウトに有効なアベ比そのものがあれば、その値を取得元付きで表示し、それもなければ「—」です。添付参照レイアウトでは266台の基準が約5,128.7671で一致します。新しい分析表の値から基準を再設定しません。分析なしの場合は従来の計算・Excelアベ比優先を維持します。

**G列の稼働日数は売上集計期間** です。カードや紫色フィルターの設置日数（基準日−設置日）には使いません。詳細では両方を別項目として表示し、売上・粗利益・原価率・P/O率・払出数・個当たり・景品単価・原価は最新分析を優先します。JSONには従来値と分析値、基準、読込情報、未照合・エラー情報を別に保存し、Excelが手元になくても復元できます。読込もUndo/Redoに対応します。

### フィルター・照合・判定設定

**表示設定 → 分析・判定・色・照合の設定** で、PO理論目安の許容偏差・標準プレイ料金、原価率40%未満／40〜50%未満／50〜70%／70%超と目標60%、照合の絶対許容額・相対許容差を変更できます。PO率・原価率は内部では比率で保存し、Excelの0.05を5%、0.60を60%と表示します。数値0と欠損は区別し、不正な単位を推測で変換しません。旧保存データの百分率は保存形式のバージョンに従って移行します。

売上フィルターはF列の売上金額で全台比較します。初期設定は20・40・60・80パーセンタイルを境界とする5段階（赤・薄橙・白・緑・黄）です。0円は有効、欠損のみ灰色です。同額は同じ色とし、全台同額は「同額のため相対比較不可」と表示します。設定から固定金額へ切替できます。異なる期間・期間不明の別ファイル・レイアウト由来の値は別々に比較し、凡例に境界金額を表示します。平均売上は読込・保存・従来アベ比の内部計算に保持しますが、画面と分析の選択肢から一時的に外しています。

異常一覧は番号・種類・内容・対応方法で検索でき、見出しでソートできます。重複番号、欠損、形式・範囲異常、売上と平均×稼働日数、売上と粗利益＋原価の不一致、機器名相違、未照合、古い再読込を区別します。重大な実績異常があるマシンの入替判定は保留にします。元Excelは修正しません。

### ダッシュボードと入替候補

ダッシュボードは管理数、入替検討数、投入予定数、未照合件数、アベ比分布、対象期間、抽出・読込日時、鮮度を表示します。割合の分母は全管理ブースで、不明も含みます。区分クリックは配置を維持した強調だけです。折りたたみや全画面の「概要」表示を保存できます。

**分析 → 入替候補** は初期設定で「アベ比50%未満・投入10日以上＝要確認」「50〜100%未満・投入7日以上＝入替検討」「100%以上＝好調」、不足は保留です。PO率・原価率・古いデータ・長期投入は理由に併記し、それだけで入替を確定しません。候補の売上推移は、商品・設置日・運営方法が一致する同日数の非重複期間だけを売上金額で比較します。従来の履歴は保持し、詳細分析の売上金額の時系列は比較可能な期間・商品・運営方法のみ使用します。一覧クリックで売り場位置を強調し、選択機器を指示書へ追加する場合は商品選択と明示的な確認が必要です。

### 運営方法別の分析

**分析 → 運営方法別分析** で現在の運営方法・機種ごとの表と売上金額の棒グラフを確認します。未設定の方法も集計します。アベ比は有効値の単純平均、PO率は売上加重平均、原価率は同じ有効対象の合計原価÷合計売上を優先します。単純平均、計算方式、有効件数、商品構成も表示します。異なる期間は別の集計行で、期間不明データを確定した期間に加算しません。

### 対象期間・履歴・復元

期間はExcel内に明記された「期間(自)」「期間(至)」等から取得し、ファイル名や稼働日数では推測しません。抽出日時とファイル名の日時は別に保持します。不明な場合は **分析 → 集計期間を手動設定** を使い、「手動設定」と記録します。同じファイルを再読込しても手動期間と初回の商品情報を保持します。

**分析 → 売上履歴** には元ファイル名、SHA-256、期間、抽出・読込日時、機器ごとの値を保存します。同一ファイルを二重登録せず、期間が重なる実績を加算しません。履歴の削除は復元可能で、削除操作だけで画面の最新実績を過去値に切り替えません。履歴と分析設定は配置JSON・一時保存JSON・自動保存へ含まれます。最大500ファイル・100万実績で、上限時は保存を中止し無断で古い履歴を削除しません。

JSONを置き換える前に、同じ場所へ **元の名前.json.bak** として直前のデータを保存します。復元するにはアプリを閉じ、`.bak` を別名の `.json` にコピーして「配置JSON読込」または「一時保存を開く」で読み込んでください。古い保存ファイルも読み込めます。元のExcelやマクロは変更しません。

Windows Actionsでは、通常の回帰テストのほか、Windowsネイティブ描画で100%・125%・150%・200%の全画面を実描画し、色と文字のピクセル、クリック詳細、ドラッグ、ズーム、選択保持、Esc復帰を確認します。EXEでも200%で同じ検証を行います。さらに300ブースの管理ナンバー照合・3テーマ・ナビ・詳細・検索・全画面・テーマに依存しない白背景PDFを100%・125%・150%で検証し、EXEでも150%で実行します。`Windows-native-visual-validation` と `Windows-validation` ArtifactにPNG・JSONを残します。実プリンターの用紙出力はこの自動検証には含まれません。

## 管理ナンバー照合・手動確認

左の **データ照合** または売り場の **分析 → 管理ナンバー照合・手動確認** を開きます。

1. レイアウトの機械番号を正規化して直接照合します。
2. 番号がなければ管理ナンバー参考表の対応を使用します。例：`L_66 → 20111右 → 20111-02`。
3. 不一致・矛盾は「照合要確認」、対応実績がなければ「レイアウト情報のみ」です。商品名から番号を推測しません。
4. **管理ナンバー参考表** タブで行を追加・修正するか、別の参考表Excelを読み込みます。
5. **マシンごとの照合** の手動設定列へ `20111右` などを入力して保存すると、ユーザーが確認した対応として保持します。「自動」で参考表へ戻し、「照合しない」で実績の照合を明示的に止められます。同じ番号を複数枠へ割り当てても、実績を二重計上しません。

詳細には管理ナンバー、機械番号の原文と照合先、照合方法、取得元、更新（読込）日時を表示します。各数値のツールチップでも取得元を確認できます。「未照合」と「アベ比不明」は別です。未照合でもレイアウトに85%があれば白区分となり、値がどちらにもない場合だけ灰色です。

元Excelの位置・サイズや商品名は変更しません。対応表と手動指定は配置JSON・一時保存・自動保存へ入り、元に戻す／やり直しにも対応します。旧JSONの欠けた照合項目は初期値を補って読み込みます。矛盾の手動修正後は、旧番号が入替予定に残っていないか商品一覧でも確認してください。

## テーマと新しい画面構成

左のナビから、ホーム・売り場レイアウト・入替指示書・入替候補・売上分析・データ照合・入荷ラベル・設定を開けます。候補・分析・照合は既存の機能を持つ画面へつながります。データ読込、商品編集、一時保存、Excel出力、プリンター・PDFの導線も維持しています。ナビは狭いウィンドウで自動的に縮小し、下のボタンでも切替できます。

上部にはページ名、対象期間、最終更新とページ連動の検索を表示します。ダッシュボードは高さをそろえた件数カードとアベ比分布を表示します。表の見出しでソートでき、数値は右寄せ・千区切り、全文はツールチップで確認できます。商品一覧の見た目のソートは印刷順の数値を書き換えません。

テーマカラーは `theme.py` に集約しています。ダークでは分析結果の区分を変えず、濃い背景と明るい文字へ変換します。テーマ切替でマシン座標・サイズ・ズームを変更しません。印刷・PDFは画面テーマを使わず、白背景と従来の分析色を維持します。標準ファイルダイアログはWindows側の表示に従います。

アイコンとグラフはQtの描画機能で実装し、新たな外部UI・アイコンライブラリは追加していません。既存のPySide6・openpyxl等の依存関係と単体EXE構成を維持します。

## 入力Excelの条件

`縦` シートの1行目に、A〜E列の見出しを次の順で用意してください。

| A | B | C | D | E |
|---|---|---|---|---|
| 稼働予定日 | 品名 | 入数 | CS数 | メーカー |

2行目以降が商品です。Excel日付・日付時刻、Excelシリアル値、`2026/11/05`・`2026-11-05`・`2026年11月05日` 等を認識し、時刻を除いて照合します。数式セルはExcelが最後に保存した計算結果を読みます。結果が空の場合はExcelで再計算して保存してください。

- 全列空欄の行は無視します。
- 不正・空欄の日付や品名の行は警告して除外します。
- 空欄の数量は空欄として扱い、不正・負の数量は警告して空欄にします。CS数の小数にも対応します。
- 同じ商品の重複行は警告して**保持**します。実際に別入荷の可能性があるため自動削除・合算しません。不要な行は出力チェックを外してください。
- 元のExcelは読み取りのみで、入力元と同じパスへの保存は拒否します。マクロは実行しません。

## 出力とレイアウト

新しい `.xlsx` に `入れ替え指示書` シートを作成します。

| ブロック | マシン | 個別の方法 | 商品全体の予定数 | 商品名 | 入数 | CS数 | 個数制限 |
|---|---|---|---|---|---|---|---|
| 左 | A | B | C | D | E | F | G |
| 右 | H | I | J | K | L | M | N |

左を上から埋めてから右に進みます。「左右交互」にも切り替えられます。B:C、I:Jの見出しは「運営方法・予定ブース数」です。マシンと個別方法は1行ずつ、予定数・商品名・入数・CS数・個数制限は実際の縦結合セルに出力します。Excel出力では、同じ「片側上限」値を従来のマシン行数の目安として使います（初期20）。高さに応じて自動改ページし、A4横向きの印刷範囲・手動改ページ・読みやすい文字サイズを保つ縮尺を設定します。

入力に `入れ替え指示書` シートがあれば、既存のマシン・方法・数量列の幅、商品行の高さ・書式、余白・印刷オプションを参考にします。旧C/Jの商品名幅は新D/Kに引き継ぎ、予定数列は新設します。通常商品の背景を保ち、必要な行高を確保します。結合セルは新しい商品ブロック用に作成し直します。元の図形・画像はコピーしません。参考シートがなくても標準レイアウトで出力できます。

Excel出力は既存書式を参考にする補助機能です。アプリの直接印刷は独立した可変行高レイアウトのため、長文時のページ数がExcelと異なる場合があります。対象商品、出力順、マシン、運営方法、優先色、個数制限は共通です。Excelファイルの印刷結果はExcelの印刷プレビューで確認してください。元Excel・マクロ・他のシートは出力に含めません。

提供された配置用xlsmでは実データの読込・配置JSON復元・PDF描画・元ファイル不変を確認しています。アプリUI／印刷見本の3枚の画像は未受領のため、画像との厳密な外観照合は未実施です。顧客の実データはリポジトリには含めません。

## 作業の一時保存

**一時保存（JSON）** で全日付の商品・数量・編集内容・出力対象・順序・選択日・レイアウト設定・売り場配置・入力元パスを保存します。以前の配置情報のないJSONも読み込めます。**一時保存を開く** で復元できます。元Excelを移動してもデータは復元できますが、参考書式が取得できない場合は標準レイアウトになります。JSONには商品情報と入力元パスが含まれますので共有先に注意してください。

`print_mode` に自動・標準・コンパクトの選択を保存します。`planned_booths` に方法別の予定数（未設定はnull）、`machine_methods` にマシン番号別の方法、`retired_machine_methods` に削除した番号の割当を保存します。`assigned_machine_count` は復元時に実際の番号から再計算します。旧形式の方法名リスト・区切り文字列・`method_counts` も読み込めます。ラベルの表示名・手動枚数・印刷設定も従来どおり保存します。予定数と割当数が違う場合、ラベル印刷前に警告しますが、ラベル枚数の計算方法と商品名だけの紙面は変わりません。

日付変更では編集内容を保持します。終了・ファイル切替時には未保存の変更の破棄を確認します。Excel出力だけでは作業全体を保存しないため、続きがある場合はJSONも保存してください。

## Windows CIでPDFの文字抽出が空になる場合

Qt 6.8.3のWindows用 `offscreen` プラグインは、通常のWindows用プラグインと違いFreeTypeのフォントデータベースを使います。既定の検索先はQt配下の `fonts` ディレクトリで、Windowsのフォントレジストリは参照せず、自動ディレクトリ検索では `.ttc` も対象になりません。フォントがない状態では文字が四角い代替図形になり、PDFにフォント・文字情報がなくなるため、Qtとpypdfのどちらでも抽出できません。

文字が取得できる場合も、Qtがフォントのcmapを逆引きする際に、同じ字形の別Unicodeを返すことがあります。Actions #14/#15の游ゴシックでは、商品名の「鬼」（U+9B3C）が「⻤」（U+2EE4）になり、NFKCだけでは一致せず3件の件数テストが失敗しました。描画欠落・商品名の重複ではありませんでした。

検証用の `normalized_pdf_text` は抽出時の空白・改行を取り除き、この既知の字体対応とNFKCを適用します。商品名の1回／ラベル3枚などの厳密な件数判定は維持し、欠落・別の商品名・重複は合格にしません。生成PDFや埋込フォント、元の商品名を変換・削除する処理ではありません。検索・コピー時に返る文字コードはビューアーやフォントで異なるため、診断には正規化前の全文と文字コードも記録します。回帰テストでは同じ字体対応を持つPDFを実際に描画し、画素の一致、埋込フォント・Unicodeマップ、Qtとpypdf双方の文字取得、商品名の描画回数、PDF保存と直接印刷経路の一致を確認します。

Actionsの **Pytest-results** Artifactには、PDF回帰テストと全テストのJUnit XMLを保存します。失敗した場合も、生成済みのレポートを取得できます。

`prize_swap/fonts.py` はWindowsのArial・メイリオ・游ゴシック等を**ファイルパスから明示登録**し、英数字と日本語のフォントを指定します。売り場レイアウトも同じ設定を使います。フォント自体が不足する環境では、空のPDFを正常扱いせず、出力前にエラーを表示します。

CIでは `scripts/prepare_ci_fonts.py` が公式Google FontsのNoto Sans JPを取得し、コミット固定URLとSHA-256を照合します。OFLライセンスも取得・検証します。システムへのインストールは不要で、`PRIZE_FONT_DIR` に指定されたディレクトリから追加登録します。CI用フォントはEXEへ同梱せず、通常のWindows実行ではシステムの日本語フォントを利用します。

Actionsの **PDF-diagnostics** Artifactには、実行OS・Qtバージョン、フォント登録前後の状態、埋込フォント／Unicodeマップ、Qtとpypdfの抽出結果、診断PDFと全ページのPNGを保存します。手元では次のコマンドで同じ診断を実行できます。

```powershell
.\.venv\Scripts\python.exe -m prize_swap.pdf_diagnostics build-diagnostics
```

テストは文字抽出の検証を維持しています。画像が描画できるだけでは合格せず、埋込フォント・Unicodeマップ・文字検索可能性・商品欠落・ページ順を確認します。テスト失敗でビルドが未実行の場合、`build-smoke/` がないのは結果であり、原因ではありません。検証ファイルが存在するときだけArtifactをアップロードします。

Qtの該当実装： [offscreenのフォントDB](https://github.com/qt/qtbase/blob/v6.8.3/src/plugins/platforms/offscreen/qoffscreenintegration.cpp)、[フォント検索先](https://github.com/qt/qtbase/blob/v6.8.3/src/gui/text/qplatformfontdatabase.cpp)、[FreeTypeの検索対象](https://github.com/qt/qtbase/blob/v6.8.3/src/gui/text/freetype/qfreetypefontdatabase.cpp)。

## 入荷ブース用ラベル印刷

入荷景品を一時保管するブースに貼る、**商品名だけ**の切り取り用ラベルです。「入荷ブース用ラベル印刷」タブで使用します。Excelは既存の **Excelを開く** から一度読み込めば共有され、上部またはタブ内の日付選択で同じ対象日へ切り替わります。

初期設定は **A4縦・1ページ7枚・太字・中央揃え・黒い枠線** です。メーカー、入数、CS数、マシン番号、タイトル、印刷日、ページ番号はラベルの紙面へ印刷しません。商品名に元から含まれている数字や記号は省略しません。

### 枚数の自動計算

マシン番号1件につき1枚を印刷します。カンマ `,`・全角カンマ `，`・読点 `、`・改行・セミコロン `;` に対応し、前後の空白と同じ番号の重複を除いて数えます。左右は別のマシンとして扱います。

| 投入予定マシン番号 | 自動枚数 |
|---|---|
| `20085右` | 1枚 |
| `20098右,20083左` | 2枚 |
| `20112左;20099左;20090右` | 3枚 |
| `20085右,20085右` | 1枚 |
| 未入力 | 1枚（画面で黄色・未設定表示） |

入替指示書の出力対象が外れている商品はラベルも対象外になります。タブの「全選択」は指示書側の出力対象を変更しません。ラベルだけを除外したい場合はこのタブの印刷チェックを外します。マシン番号は枚数計算・確認用に画面だけに表示し、紙面には商品名だけを描画します。

通常は「手動枚数」を **自動** のまま使います。必要な商品だけ数値を入力して上書きできます。セルの0は「自動」を意味します。**自動枚数に戻す** は選択行を戻し、行が未選択なら表示中の全商品を戻します。手動枚数がある間は、マシン番号の変更で上書きしません。印刷から除外するには0枚ではなく印刷チェックを使ってください。

### 編集と連携

- 表示名を編集しても入替指示書の商品名は変わりません。**元の商品名に戻す** で自動取得に戻せます。
- 商品名、マシン番号、出力チェック、日付、読込商品一覧の変更を自動反映します。表示名を個別に編集した商品は、その表示名を保持します。
- **↑ / ↓** で複数選択した商品を並び替えできます。出力順は指示書と共通で、双方へ反映されます。同じ商品のラベルは連続します。例：A×1、B×2、C×3 → A、B、B、C、C、C。
- **一時保存JSON** にはラベルの表示名・チェック・手動枚数・印刷設定も含みます。旧形式のJSONも引き続き読み込めます。日付切替では別日のラベル編集を失いません。

### 印刷設定と文字の収まり

右側で1ページ4〜10枚、文字サイズの自動／手動、太字／極太、中央／左揃え、枠線0.5〜4ptを設定します。極太はフォントへBlackウェイトを指定し、利用できる書体に応じて描画します。

自動モードは `QFontMetricsF` と実際の折り返しレイアウトで幅・高さを計測し、8〜256ptの範囲で収まる最大の整数ptを選びます。日本語・英数字・明示改行に対応し、省略記号で置換しません。極端に長い商品名や小さい文字になる場合は警告します。8ptでも収まらない入力、または手動サイズで収まらない入力は出力を中止し、既存PDFを保持します。

**印刷プレビュー／PDF保存／直接印刷** は同じ描画処理を使用し、既存の指示書とプリンターのDPI変換、ページ範囲、部数、逆順処理、PDFの安全な保存を共有します。標準印刷ダイアログでプリンター・範囲・部数を選べます。このタブを開いている間は画面最上部の印刷ボタンもラベル用として動作します。初期余白は6mmで、プリンターの印刷可能領域から各枠の大きさを計算します。

PDFの紙面寸法、全ページの描画と文字抽出、実際の文字座標が枠内にあること、枚数・順序・除外をテストします。Windows EXEの自動スモークテストにもラベルPDFとプレビューを含みます。`PDF-diagnostics` / `Windows-validation` Artifactから診断PDFやJSONを確認できます。実プリンターでの用紙出力は、Windows実機で別途確認してください。

ラベル機能の実装は `labels_data.py`（表示名・対象・枚数）、`labels_ui.py`（タブ）、`labels_printing.py`（文字実測・枠配置）です。`printing.py` の共通処理を利用し、既存の指示書はA4横向き、ラベルはA4縦向きのまま別のレイアウトを維持します。

Windows CIの **PDF-diagnostics** Artifactには、10・20・30・40商品の自動最適化PDFと描画PNG、実際のページ数・フォントサイズ・左右の高さも保存します。

## マシン詳細・売上分析・グラフ連携

カードをクリックすると、機械番号／管理ナンバー、機種、商品名、照合状態、更新日時と、アベ比・売上金額・理論PO目安・原価率・PO率・投入日数のKPIを表示します。従来の情報と編集はスクロールで確認できます。狭い画面は縦方向へ切り替え、前回のウィンドウサイズを保存します。

5項目のレーダーは**実際の値と単位**を表示し、内部の0〜100正規化値は表示しません。欠損はデータなし／未評価で、完全な五角形を作りません。アベ比は従来の計算、投入日数は設置日から算出します。投入日数は新しさであり、売上不振そのものではありません。売上は同じ期間の全機種を対象に売上金額の同順位平均順位で比較し、同額は同じ評価です。総合点は作りません。

### 理論PO率

理論目安 = 1プレイ料金 × 目標原価率 ÷ 景品1個の原価。270円・100円プレイ・60%なら22.22%です。原価はユーザー確認の手動修正を優先し、なければExcelの明示的な景品原価列／O列景品単価を使用します。P列の集計原価は使いません。商品名末尾の独立した数字は候補として提示し、確認ボタンで確定するまでは計算に使いません。商品が変われば以前の確認原価は使いません。

マシン詳細で確認原価と「金額・その料金での回数・確認済み」を設定できます。正式な料金列があれば最優先し、なければマシン設定、最後に標準100円を仮設定として使用します。500円6回などは1回あたりで計算します。目標原価率・標準料金・許容偏差は分析設定で変更できます。原価0・欠損・不正条件は計算不可です。100%を超える計算値は丸めず警告します。

PO率は獲得回数÷プレイ回数の比率です。ExcelのP/O率は変更せず、払出数を獲得回数に勝手に換算しません。添付Excelは払出数の個数／回数・割引条件の定義を明示していないため、理論値は目安です。料金の仮設定も取得元とともに表示します。PO評価の内部値は `max(0,100×(1-|実測-理論|/理論))`、表示色は設定した許容偏差に従います。

### 分布画面と詳細分析

左の**売上分析**はメイン画面内で開き、最初にアベ比・売上金額・PO率・原価率・投入日数・機種の6分布をカードで表示します。ウィンドウ幅に応じて3／2／1列に切り替え、横棒・円・ドーナツを選択できます。運営方法分布も追加可能です。対象台数・不明件数・平均／中央値・凡例を表示し、長い凡例と金額境界はホバーで確認できます。区分をクリックすると全台の配置を保って売り場で強調し、カードの「詳細」で詳細分析へ進みます。

**詳細分析**には従来の11形式（横棒・縦棒・円・ドーナツ・折れ線・面・積み上げ棒・散布図・ヒストグラム・レーダー・クロス集計）、AND条件、CSV／Excel・画像出力を残しています。通常の指標・集計軸は主要項目に絞り、「その他の指標・集計軸」で粗利益・払出数などへ展開できます。平均売上は展開しても表示しません。縦棒ラベルの斜め表示を廃止し、水平ラベルと正式名称のツールチップを使用します。

### 入替候補ページ

左の**入替候補**はメイン画面内で開きます。要確認・入替検討・好調・データ不足・登録済みをKPIと文字ラベル付きの色で確認できます。検索、機種／運営方法／状態の絞込、数値ソート、マシン詳細、配置の強調、明示的な商品選択と確認後の指示書登録に対応します。選択だけでは登録しません。候補の除外理由を保存し、Excel再読込や再起動でも維持します。「除外済みも表示」から復帰できます。判定のアベ比・設置日・期間・商品・鮮度のルールは維持し、売上推移は同日数・非重複期間の商品／設置日／運営方法が一致する場合だけ評価します。

適さない形式は無効になり、理由をツールチップや注意欄に表示します。円・ドーナツは構成件数／件数割合のみを扱い、比率の平均や売上を無条件に円にしません。レーダーは1台を指定します。折れ線・面は複数の確定期間に同じ商品・設置日・運営方法の実績がある場合だけ利用できます。重複期間、文脈不明、重大な異常のある実績を除外します。旧履歴に運営方法の記録がない場合は推測せず比較しません。履歴の確認はバックグラウンドで行います。

集計は合計・単純平均・中央値・最小・最大・件数・件数割合・売上加重平均・原価率の合計原価÷合計売上に対応します。比率の合計はできません。期間や有効値の分母を表示し、欠損値を0に置き換えません。レイアウト由来など期間が不明な指標は、分析表の確定期間の指標と分離して集計します。従来のPO率・原価率の優先集計方式は **運営方法別（従来指標）** タブにも残しています。

### グラフから売り場を確認

棒、円の区分、散布点、ヒストグラムの階級、期間の点、積み上げのセグメント、集計表のセルをクリックすると、そのデータに含まれるマシンを売り場で強調します。全マシンを表示したまま、非該当のカードを薄くします。番号・商品名から機械を推測せず、集計時のマシンIDを使用します。

**分析による強調表示を解除** すると、通常の検索・フィルター・倍率を維持して分析の強調だけを解除します。全画面にも解除ボタンがあります。座標・サイズ・配置順序は変更しません。

### 分析データの保存

**CSV・Excel出力** から集計結果、全項目の詳細、グラフデータ、クロス集計を保存できます。Excelには設定・期間・取得元も含めます。元の読込Excelと同じパスには保存できません。

CSVはExcelで開きやすいUTF-8 BOM付きです。原価率・PO率は内部比率（0.05=5%）と明記して保存します。Excelでは数値として保持し、%書式で表示します。欠損は空欄、0は0です。商品名などを数式として実行させないよう、CSVの先頭記号を保護し、Excelでは文字列型で保存します。

分析の選択条件・グラフ形式・並び順・詳細サイズは配置JSON／一時保存に含まれます。旧形式v1〜v3の保存ファイルも読み込めます。手動編集した項目の取得元と日時も保持し、新しい有効な分析表を読み込んだ場合は従来どおり分析表の実績を優先します。

ダークモードでもアベ比50〜100%未満は明るい白系（#F3F4F6）・濃い文字です。不明のグレーと区別します。画面のテーマは印刷・PDFへ反映しません。

## ホーム・選択台分析・入替候補の一括追加

起動時はホームを表示します。KPIと機能タイルから売り場、売上分析、入替候補、指示書、入荷予定、照合、ラベル、設定へ移動できます。「入荷予定」は既存商品の登録日／稼働予定日一覧で、入荷日を推測して補いません。

売り場上部の **通常操作／範囲選択／個別選択** を切り替えます。範囲選択はカードと少しでも重なれば対象（「中心点のみ」も選択可）、Shiftドラッグで追加、Ctrlクリックで切替です。全選択、解除、ビューにフォーカスがある場合のCtrl+A／Escも利用できます。文字入力欄のCtrl+Aはテキスト選択を優先します。狭い画面では「選択」メニューに同じ操作をまとめます。全画面のEscは従来どおり全画面解除です。

選択は永続マシンUIDを使って共有し、配置、検索、分析色とは別に扱います。「選択台を売上分析」または分析ページの **全台／レイアウト選択中の台** で対象を切り替えられます。ユーザーが明示的に全台を選んだ場合はその指定を維持します。欠損台も対象件数に含め、売上あり／なしを別表示します。レーダーの売上比較母集団は選択台に狭めません。

候補のチェックボックス、マシン詳細、売り場の選択は同じ選択状態です。候補一覧の **指示書へ追加** と、**要確認／入替検討／両区分／選択中** の一括追加は、台数と重複件数の確認後に実行します。現在編集中の日付の指示書に下書き行を作り、機械番号→参考表の照合番号→管理ナンバーの順に入力します。両方不明なら空欄です。内部UIDと正規化番号で重複を防ぎます。

下書きの新商品名・入数・CS数・入替後の運営方法は空欄です。現行商品名、現行運営方法、売上、アベ比、投入日数、判定理由は別の引継ぎ情報として保存し、商品名・番号セルのツールチップで確認できます。日付は編集中の指示書への所属を示し、確定入替日は別途未設定です。新規追加時の出力チェックはONです。新商品名・数量・運営方法が空欄でもメモとして印刷でき、既存データのOFFは維持します。既存商品の選択・確認による登録も従来の「入替予定へ登録」に残しています。

適正PO率は **目標原価率×1プレイ料金÷確認済み景品単価**。元の景品運営分析表のP/O率はユーザー確認に基づき「景品獲得数÷プレイ回数」として読み込みます。原値を別に保持し、別定義のデータは設定で分離できます。末尾の020／050等は20／50円の候補とし、型番との混同を避けるため確認して使用します。手動確認原価を優先し、正式単価との差は警告します。料金不明時の100円は仮設定、実測投入金額・プレイ回数があれば有効単価を優先します。差は符号付きptで表示し、100%超の適正値は丸めず未評価として警告します。

分析設定では5段階の売上境界、PO率の内側／外側許容差、原価率境界、目標原価率、料金、レーダー基準を保存できます。分布タイルは↑で並べ替え、拡大・詳細表示が可能です。投入日数は0〜6／7〜9／10〜13／14〜20／21日以上に分け、10日以上の紫と対応します。スコアは内部座標にだけ使用し、画面には実数値を表示します。同額・単独の売上比較は未評価です。


## 指示書の編集と入替予定地図

指示書一覧の「指示の編集」から、手動追加・詳細編集・複製・削除・取り消しができます。既存の表形式とセル編集、全選択・全解除、上へ・下へは維持しています。Deleteは削除確認、Ctrl+Z/Ctrl+Yは表の編集履歴に適用します。商品名は入荷予定から選択・自由入力・空欄に対応し、メーカー・数量・管理ナンバー・備考も編集できます。

商品未定は画面で「商品未定」、印刷では空欄です。マシンだけの指示や運営方法未割当でも、出力チェックONなら出力します。OFFは対象外のままです。0件時の「出力対象を全選択」は現在の日付・検索／絞り込み範囲だけを対象にし、別の日付のチェックを変更しません。

Excel更新時は「手動編集を優先」が初期選択です。「Excelの最新値を使用」「項目ごとに確認」も選択できます。曖昧な商品照合は既存行を破壊せず保持します。指示の自動保存は売り場JSONと同じフォルダーの `<売り場保存名>-instructions-autosave.json`、置換前のデータは `.bak` に保存します。「一時保存」「一時保存を開く」でも全情報を保存・復元できます。

売り場の「選択台を候補へ追加」は手動登録属性を付け、自動判定と選択状態を維持します。候補からの単体／一括追加は確認後に既存の指示書へ反映します。現在の商品と新しく投入する商品は分離し、追加元と追加方法はツールチップ・詳細編集で確認できます。内部IDと、正規化番号／参考表／管理番号の安全な照合で重複追加を防ぎます。

指示書内の「入替予定地図」は出力対象ブースに番号を付け、売り場の座標・サイズをそのまま参照します。地図は青いカードと番号だけを表示し、クリックで対応する指示を選択します。21以上も丸枠と数字を描くため、丸数字フォントに依存しません。順序変更で表示番号を再計算し、指示IDと割当IDは保持します。

位置不明・複数候補は地図の一覧に表示します。ダブルクリックで実在マシンを選択でき、架空の位置は生成しません。全体フィット・ホイールズーム・ドラッグ移動に対応し、画面倍率は印刷倍率に影響しません。「全登録指示」はOFFも確認するための地図オプションです。

地図はA4/A3、縦・横・自動方向に対応し、番号が小さくなる場合は実配置を保って複数ページに分割します。右上の出力方式で「指示書のみ」（初期値）・「地図のみ」・「指示書＋地図」を選択できます。混在用紙のプレビューは実際に生成したPDFを表示します。プリンタードライバーが用紙変更に対応しない場合は、指示書と地図を分けて印刷してください。

従来の指示書のA4横、列幅、余白、商品名、行高、左右配置、ページ最適化、日本語フォントは維持し、マシン欄内の番号だけを最小限追加しています。基準PDFは `tests/baselines/instructions/` にあり、20／40商品の寸法・改ページを回帰テストで比較します。印刷物はダークテーマでも白背景です。
