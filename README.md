# プライズ景品 入替指示書メーカー

ゲームセンターの入荷Excelから日付別の商品を抽出し、マシン番号・運営方法などを設定して、左右2ブロックの入替指示書を出力する日本語Windowsデスクトップアプリです。

## Windowsで使う（Python不要）

1. GitHubの **Actions → Windows portable EXE** で成功した実行を開きます。
2. **Artifacts → PrizeSwapInstructionMaker-windows-x64** をダウンロードして展開します。中のZIPも展開してください。
3. `PrizeSwapInstructionMaker.exe` を起動します。インストールは不要です。
4. **Excelを開く** で `.xlsx` または `.xlsm` を選びます。
5. カレンダーまたは登録日一覧から日付を選びます。青い日付は商品がある日です。該当商品がない日は0件表示になります。
6. 表で商品名・入数・CS数・順序を編集します。順序が小さい商品から出力し、同じ番号の場合は元の順を保ちます。出力チェックを外すと除外できます。
7. 商品行を選び、右側でマシン番号や運営方法、優先入替、個数制限を編集し、**選択商品に適用** を押します。入力途中の詳細欄はこのボタンで確定してください。
8. **プレビュー** で左右配置と対象商品を確認し、**Excel出力** で保存先を指定します。

表は横スクロール可能で、列の境界をドラッグして幅を変えられます。CtrlまたはShiftで複数商品を選択し、一括編集できます。一括編集では右側の先頭商品を元に、**適用する項目だけ** チェックしてください。商品名・数量・順序は表で個別に編集します。

マシン番号は `20085右,20098左` のようなカンマ区切り、または改行で入力し、追加・削除できます。半角数字と末尾の「左」「右」に対応します。表への直接入力も可能です。出力時はセル内改行になります。

運営方法は複数チェックと自由入力に対応します。「優先入替」の商品は左右の該当ブロック7セルを薄いピンクにします。個数制限は「制限なし」「各①〜各⑩」「トータル①〜トータル⑩」をそのまま出力します。

## 入力Excelの条件

`縦` シートの1行目に、A〜E列の見出しを次の順で用意してください。

| A | B | C | D | E |
|---|---|---|---|---|
| 稼働予定日 | 品名 | 入数 | CS数 | メーカー |

2行目以降が商品です。Excel日付・日付時刻、Excelシリアル値、`2026/11/05`・`2026-11-05`・`2026年11月05日` 等を認識し、時刻を除いて照合します。数式セルはExcelが最後に保存した計算結果を読みます。結果が空の場合はExcelで再計算して保存してください。

- 全列空欄の行は無視します。
- 不正・空欄の日付や品名の行は警告して除外します。
- 空欄の数量は空欄として扱い、不正・負の数量は警告して空欄にします。CS数の小数にも対応します。
- 同じ商品の重複行は警告して**保持**します。実際に別入荷の可能性があるため自動削除・合算しません。不要な行は出力チェックを外してください。
- 元のExcelは読み取りのみで、入力元と同じパスへの保存は拒否します。マクロは実行しません。

## 出力とレイアウト

新しい `.xlsx` に `入れ替え指示書` シートを作成します。

| ブロック | マシン | 運営方法 | 商品名 | 優先 | 入数 | CS数 | 個数制限 |
|---|---|---|---|---|---|---|---|
| 左 | A | B | C | D | E | F | G |
| 右 | H | I | J | K | L | M | N |

標準は1ページ左右各20商品、左を上から埋めてから右に進みます。「左右交互」にも切り替えられます。行数は1〜50で設定可能です。超過分は次ページに配置し、A4横向きの印刷範囲・手動改ページ・全体を収める縮尺を設定します。長い商品名や大量のマシン番号は文字が収まるか最終確認してください。

入力に `入れ替え指示書` シートがあれば、A〜N列の列幅、3行目以降の商品行の行高・セル書式、余白・印刷オプションを参考にします。通常商品の背景は参考行の色を保ちます。タイトルと見出しは生成します。結合セル・図形・画像・複雑な帳票の構造はコピーしません。参考シートがなくても標準レイアウトで出力できます。

アプリ内プレビューは**配置・内容の確認用**です。Excelと同じフォント描画や印刷結果を保証するものではありません。実際の折返しや印刷結果はExcelの印刷プレビューで確認してください。元Excel・マクロ・他のシートは出力に含めません。

実際の見本Excel・画像はまだ本リポジトリにありません。実物と一致するテンプレート調整と実マクロ付きファイルの受入確認は、見本提供後に必要です。

## 作業の一時保存

**一時保存（JSON）** で全日付の商品・数量・編集内容・出力対象・順序・選択日・レイアウト設定・入力元パスを保存します。**一時保存を開く** で復元できます。元Excelを移動してもデータは復元できますが、参考書式が取得できない場合は標準レイアウトになります。JSONには商品情報と入力元パスが含まれますので共有先に注意してください。

日付変更では編集内容を保持します。終了・ファイル切替時には未保存の変更の破棄を確認します。Excel出力だけでは作業全体を保存しないため、続きがある場合はJSONも保存してください。

## 開発環境（Python 3.12）

Windows PowerShellでリポジトリのフォルダを開き、実行します。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

テスト：

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
.\.venv\Scripts\python.exe -m pytest -q
```

Linuxクラウド環境では `python3.12 -m venv .venv`、`.venv/bin/python -m pip install -r requirements.txt` を実行します。ヘッドレスUIテストは `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q` です。デスクトップ利用時は `QT_QPA_PLATFORM` を設定せず `.venv/bin/python main.py` で起動します。

## Windows x64 EXEのビルド

Windows x64上で次を実行します。LinuxからWindows EXEを直接生成する構成ではありません。

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm --onefile --windowed --noupx --name PrizeSwapInstructionMaker main.py
```

`dist/PrizeSwapInstructionMaker.exe` が完成品です。Pythonを同梱する単体EXE、コンソール非表示、UPX不使用です。初回起動時は一時展開に時間がかかることがあります。未署名EXEのためDefender/SmartScreenの誤検知を完全には防げません。配布元・Actions実行内容を確認してください。

## GitHub Actions

`.github/workflows/build-windows.yml` が 各ブランチへのpush・プルリクエスト・`v`から始まるタグ・手動実行に対応します。Windows x64/Python 3.12で依存導入 → pytest → PyInstaller → ZIP作成 → Artifact保存を順に実行します。テストに失敗した場合はビルドしません。

GitHubへ変更をpush後、**Actions → Windows portable EXE → Run workflow** から実行できます。タグ `v1.0.0` 等をpushすると、成功したZIPをGitHub Releaseにも添付します。通常のビルドジョブは読取権限、タグ時のReleaseジョブだけ書込権限を持ちます。実行履歴とArtifactsの確認をもってWindowsビルド成功と判断してください。

## 構成と検証範囲

- `prize_swap/core.py`：商品モデル、Excel読込、入力検証、JSON保存・復元
- `prize_swap/exporter.py`：左右配置、参考書式、新規Excel出力
- `prize_swap/ui.py`：日本語GUI、編集、一括適用、配置プレビュー
- `tests/`：入出力、日付、重複・不正値、書式、左右順、ページ追加、日本語パス、元ファイル保護、JSON復元、UI一括編集

xlsmテストはマクロ形式の合成OOXMLを使用し、マクロの実行や実ファイルのVBA動作を検証するものではありません。Windows上での操作、EXE起動、プリンタ別の印刷結果は別途受入確認してください。
