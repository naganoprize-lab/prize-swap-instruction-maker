# プライズ景品 入替指示書メーカー

ゲームセンターの入荷Excelから日付別の商品を抽出し、マシン番号・運営方法などを設定して、左右2ブロックの入替指示書を出力する日本語Windowsデスクトップアプリです。

## Windowsで使う（Python不要）

1. GitHubの **Actions → Windows portable EXE** で成功した実行を開きます。
2. **Artifacts → PrizeSwapInstructionMaker-windows-x64** をダウンロードして展開します。中のZIPも展開してください。
3. `PrizeSwapInstructionMaker.exe` を起動します。インストールは不要です。
4. **Excelを開く** で `.xlsx` または `.xlsm` を選びます。
5. カレンダーまたは登録日一覧から日付を選びます。青い日付は商品がある日です。該当商品がない日は0件表示になります。
6. 商品一覧のセルをクリックして、商品名・入数・CS数・順序・マシン番号を直接編集します。Enterまたは別のセルへの移動で確定します。
7. 運営方法のセルはチェック可能なドロップダウンで複数選択できます。文字入力で独自の方法も追加できます（カンマ区切り）。個数制限はセル内プルダウンで選択します。
8. 上部の **印刷プレビュー** で確認し、**直接印刷** または **PDF保存** を実行します。Excelファイルが必要なときは下部の **Excel出力** を使います。

白いカード、淡いグレーの背景、落ち着いたグリーンを基調にしたUIです。商品一覧が画面中央を使用し、右側の一括編集パネルはありません。行高34px、フォント約10pt、交互背景色・選択行ハイライトに対応します。列境界をドラッグして幅を変えられ、横スクロールと商品名のツールチップも使えます。

検索は商品名・メーカー・マシン番号・運営方法に対応します。「全選択」「全解除」は**検索・絞り込みで表示中の商品の出力チェック**を変更します。Ctrl/Shiftで行を複数選択し、「↑ 上へ」「↓ 下へ」で並び替えできます（検索・絞り込みは解除してください）。順序の数値を直接編集しても並びが変わります。同順位は元の順序を保ちます。

印刷・PDF・Excel出力は、検索に関係なく**選択日の出力チェックが入っている商品すべて**が対象です。日付を変えても編集内容を保持します。

マシン番号は `20085右,20098左` のように入力できます。セル内の複数行入力・貼り付けにも対応し、右端の「▾」から売り場レイアウトに登録済みの番号を追加・解除できます。半角数字と末尾の「左」「右」に対応し、出力時はセル内改行です。運営方法も複数選択した文字列を改行で出力します。

優先入替の商品は表・印刷の該当ブロック7セルを薄いピンクにします。個数制限は「制限なし」「各①〜各⑩」「トータル①〜トータル⑩」をそのまま出力します。

## 直接印刷・プレビュー・PDF

PySide6の `QPrinter`・`QPrintDialog`・`QPrintPreviewDialog`・`QPainter` を使用します。プレビュー・実プリンター・PDFは同じページ計算と描画処理を通ります。初期設定はA4横、余白6mm、本文約11ptの太めの文字と黒い罫線です。日本語はWindowsの日本語フォント（標準のフォントフォールバック）を利用します。

商品名・複数マシン・運営方法を折り返して行高を計算し、左右の同じ段は高い方の行高に揃えます。「1ブロック上限」は最大行数です。印刷可能な高さを超える場合は行数を自動的に減らして次ページへ進み、商品行の途中では分割しません。日付・印刷日（日本時間）・ページ番号を表示します。

1商品だけでページの高さを超える極端な入力は、文字を小さくしたり切り捨てたりせず、修正を促して出力を中止します。PDFは一時ファイルを経由して保存するため、失敗時は既存のPDFを保持します。上書きは保存ダイアログで確認します。

「直接印刷」はWindows標準のダイアログでプリンター、部数、ページ範囲などを指定します。プレビューと実印刷で同じ用紙・向き・余白を使ってください。プリンタードライバーの印刷可能領域や設定変更により改ページが変わる場合があります。**実プリンターからの用紙出力はWindows実機で確認が必要**です。

## 売り場レイアウトとマシン管理

「売り場レイアウト」タブ → **レイアウトExcel読込** で `.xlsx` / `.xlsm` を選びます。商品用の「縦」シートがなくても、配置専用Excelとして読み込めます。

読み取り対象は `投入中レイアウト` シートの `L_66` / `R_66` のような参照IDセルです。その右隣のセルを現在の商品名として取得し、Excelの列幅・行高による位置関係をキャンバスに配置します。売上・PO率・設置日などは表示しません。図形ベースのレイアウトや任意の別書式の自動解釈には対応しません。

`管理番号参考値` シートのA列=参照ID、B列=実マシン番号を使います。提供された `レイアウト_参照値.xlsm` は298枠に対して対応表が6件です。実番号が不明な枠は「未設定」と参照IDを表示し、`L_66` を `66左` などと推測しません。参照IDの重複で同じ実番号になる枠も未設定として警告します。各枠をダブルクリックして実番号を登録してください。

- **マシン追加**：番号、左右、種別、現在の商品を設定して配置。登録済みの番号と左右の組み合わせの重複を拒否します。
- **移動・サイズ**：ドラッグで移動、選択した枠の四隅でサイズ変更。Ctrl+クリックで複数選択し、一括移動できます。背景の範囲選択にも対応します。
- **複製**：Ctrl+Dまたは「複製」。少しずらして配置し、番号は未設定になります。ダブルクリックで新番号を確定してください。
- **削除**：Deleteまたは「削除」。複数枠をまとめて削除できます。確認ダイアログを出し、入替予定で使用中ならその中で警告します。
- **整列**：左揃え、上揃え、横・縦の等間隔に対応。等間隔は3枠以上で行い、両端の間に枠が収まらない場合は警告します。
- **元に戻す／やり直し**：Ctrl+Z / Ctrl+Y。追加、削除、複製、移動、サイズ変更、整列、番号変更、配置の読み込み・リセットが対象です。
- **表示**：Ctrl+ホイールで拡大縮小、「全体表示」「100%」で表示倍率を調整します。大きい売り場は拡大して編集してください。

入替予定のある実番号の枠は薄い黄色、選択日の優先入替がある枠は薄いピンクになります。削除・番号変更で入替予定は自動的に消去・変更しません。元の予定が残ることを警告し、商品一覧で正しいマシンへ修正できます。配置に存在しない番号が印刷・PDF対象にある場合にも確認を表示します。

**保存** は配置専用JSON、下部の **一時保存** は商品データと配置を含むJSONです。位置・サイズ・追加削除・番号・種別・商品名・元の配置を保存します。配置は編集後約0.8秒で自動保存され、再起動時に復元します。通常のWindows実行では `%LOCALAPPDATA%/PrizeSwapInstructionMaker/floor-autosave.json` に保存します。自動保存に失敗した場合はステータスに表示します。Undo履歴と選択状態は再起動後には復元しません。

Excel再読込時は、現在の編集済み配置を保持するかExcel配置へ置き換えるか選択できます。保持した場合は「元の配置」のみ更新します。**元のExcel配置へ戻す** で最後に読み込んだ配置へ戻せます。どの操作でもExcelは読み取り専用で、元ファイルへ書き戻しません。

レイアウトタブの **印刷** は売り場全体をA4横1ページに収めます。大規模売り場では文字が小さくなるため、これは全体配置の確認用です。入替指示書の印刷は画面上部から行ってください。

## 入力Excelの条件

`縦` シートの1行目に、A〜E列の見出しを次の順で用意してください。

| A | B | C | D | E |
|---|---|---|---|---|
| 稼働予定日 | 品名 | 入数 | CS数 | メーカー |

2行目以降が商品です。Excel日付・日付時刻、Excelシリアル値、`2026/11/05`・`2026-11-05`・`2026年11月05日` 等を認識し、時刻を除いて照合します。数式セルはExcelが最後に保存した計算結果を読みます。結果が空の場合はExcelで再計算して保存してください。

- 全列空欄の行は無視します。
- 不正・空欄の日付や品名の行は警告して除外します。
- 空欄の数量は空欄として扱い、不正・負の数量は警告して空欄にします。CS数の小数にも対応します。
- 同じ商品の重複行は警告して**保持**します。実際に別入荷の可能性があるため自動削除・合算しません。不要な行は出力チェックを外してください。
- 元のExcelは読み取りのみで、入力元と同じパスへの保存は拒否します。マクロは実行しません。

## 出力とレイアウト

新しい `.xlsx` に `入れ替え指示書` シートを作成します。

| ブロック | マシン | 運営方法 | 商品名 | 優先 | 入数 | CS数 | 個数制限 |
|---|---|---|---|---|---|---|---|
| 左 | A | B | C | D | E | F | G |
| 右 | H | I | J | K | L | M | N |

標準は1ページ左右各20商品、左を上から埋めてから右に進みます。「左右交互」にも切り替えられます。行数は1〜50で設定可能です。超過分は次ページに配置し、A4横向きの印刷範囲・手動改ページ・全体を収める縮尺を設定します。長い商品名や大量のマシン番号は文字が収まるか最終確認してください。

入力に `入れ替え指示書` シートがあれば、A〜N列の列幅、3行目以降の商品行の行高・セル書式、余白・印刷オプションを参考にします。通常商品の背景は参考行の色を保ちます。タイトルと見出しは生成します。結合セル・図形・画像・複雑な帳票の構造はコピーしません。参考シートがなくても標準レイアウトで出力できます。

Excel出力は既存書式を参考にする補助機能です。アプリの直接印刷は独立した可変行高レイアウトのため、長文時のページ数がExcelと異なる場合があります。対象商品、出力順、マシン、運営方法、優先色、個数制限は共通です。Excelファイルの印刷結果はExcelの印刷プレビューで確認してください。元Excel・マクロ・他のシートは出力に含めません。

提供された配置用xlsmでは実データの読込・配置JSON復元・PDF描画・元ファイル不変を確認しています。アプリUI／印刷見本の3枚の画像は未受領のため、画像との厳密な外観照合は未実施です。顧客の実データはリポジトリには含めません。

## 作業の一時保存

**一時保存（JSON）** で全日付の商品・数量・編集内容・出力対象・順序・選択日・レイアウト設定・売り場配置・入力元パスを保存します。以前の配置情報のないJSONも読み込めます。**一時保存を開く** で復元できます。元Excelを移動してもデータは復元できますが、参考書式が取得できない場合は標準レイアウトになります。JSONには商品情報と入力元パスが含まれますので共有先に注意してください。

日付変更では編集内容を保持します。終了・ファイル切替時には未保存の変更の破棄を確認します。Excel出力だけでは作業全体を保存しないため、続きがある場合はJSONも保存してください。

## 開発環境（Python 3.12）

Windows PowerShellでリポジトリのフォルダを開き、実行します。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

テスト：

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
.\.venv\Scripts\python.exe -m pytest -q
```

Linuxクラウド環境では `python3.12 -m venv .venv`、`.venv/bin/python -m pip install -r requirements.txt` を実行します。ヘッドレスUIテストは `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q` です。デスクトップ利用時は `QT_QPA_PLATFORM` を設定せず `.venv/bin/python main.py` で起動します。

## Windows x64 EXEのビルド

Windows x64上で次を実行します。LinuxからWindows EXEを直接生成する構成ではありません。

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --clean --noconfirm --onefile --windowed --noupx --name PrizeSwapInstructionMaker main.py
```

`dist/PrizeSwapInstructionMaker.exe` が完成品です。Pythonを同梱する単体EXE、コンソール非表示、UPX不使用です。初回起動時は一時展開に時間がかかることがあります。未署名EXEのためDefender/SmartScreenの誤検知を完全には防げません。配布元・Actions実行内容を確認してください。

## GitHub Actions

`.github/workflows/build-windows.yml` が 各ブランチへのpush・プルリクエスト・`v`から始まるタグ・手動実行に対応します。Windows x64/Python 3.12で依存導入 → pytest → PyInstaller → **生成EXEでUI・印刷プレビュー・PDF・JSON・配置のスモークテスト** → ZIP作成 → Artifact保存を順に実行します。テストに失敗した場合はビルドしません。

GitHubへ変更をpush後、**Actions → Windows portable EXE → Run workflow** から実行できます。タグ `v1.0.0` 等をpushすると、成功したZIPをGitHub Releaseにも添付します。通常のビルドジョブは読取権限、タグ時のReleaseジョブだけ書込権限を持ちます。実行履歴とArtifactsの確認をもってWindowsビルド成功と判断してください。

## 構成と検証範囲

- `prize_swap/core.py`：商品モデル、Excel読込、入力検証、JSON保存・復元
- `prize_swap/exporter.py`：左右配置、参考書式、新規Excel出力
- `prize_swap/ui.py`：カード型GUI、検索、日付選択、各操作
- `prize_swap/table.py`：QAbstractTableModel、セル内編集デリゲート
- `prize_swap/printing.py`：可変行高、改ページ、共通QPainter描画
- `prize_swap/floor_data.py`：マシンモデル、配置Excel読込、JSON検証
- `prize_swap/floor.py`：売り場キャンバス、配置編集、Undo/Redo、自動保存
- `prize_swap/smoke.py`：生成EXEでも動くスモークテスト
- `tests/`：既存Excel入出力とJSON互換、実際のセル操作、配置ドラッグ・サイズ変更・ショートカット、PDFの全ページ描画・A4寸法・商品欠落・文字領域の検証

xlsmテストはマクロ形式の合成OOXMLを使用し、マクロの実行や実ファイルのVBA動作を検証するものではありません。Windows上での操作、EXE起動、プリンタ別の印刷結果は別途受入確認してください。

生成EXEのスモークテストは、実プリンターへジョブを送信しません。Actionsの `Windows-validation` Artifactに `report.json` と検証用PDF・JSON・Excelを保存します。`report.json` の `ok: true` は自動検証の成功で、`physical_printer_tested: false` は実プリンター未確認を意味します。

手元で実行する場合：

```powershell
.\dist\PrizeSwapInstructionMaker.exe --smoke-test build-smoke
```

Linuxでの同等チェックは `.venv/bin/python main.py --smoke-test /tmp/prize-smoke` です。Windows用EXEの起動成功はWindows Actionsの実行結果で確認してください。Linux上のテストだけではWindowsビルド成功や実機印刷成功を意味しません。
