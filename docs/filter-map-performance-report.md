# 売上順位・共通判定・地図・軽量描画の変更報告

## 修正原因と実装

- 旧売上判定は、画面の管理ブースから期間・取得元ごとに母集団を作っていた。添付の参考表は実際に6組しかなく、現在実績に照合できた6台だけが比較対象になっていた。読込金額やカンマ変換の異常ではなかった。
- ユーザー確認により、現在の売上Excelの有効な全304台を共通基準にした。未照合レコードは基準計算だけに利用し、別ブースへ割り当てない。検索・選択・表示範囲・機種で基準を変えない。
- 順位は競争順位（自分より売上が高い台数＋1）、上位割合は「高い台数÷（有効台数−1）」とする。同額は同順位・同色。境界上は高い側の帯に属する。全台同額・1件のみは相対比較不可。0円は有効、欠損・異期間は別状態とする。
- 黄・緑・白・橙・赤の初期配色、4境界、固定金額／順位方式、5色の編集と初期化を追加。旧保存設定には安全な初期値を補う。
- 期間不明のレイアウト数値は、304台の母集団に加えず参考比較と明記する。既知の異期間データは対象期間外とし、現在期間の実績と混同しない。
- フィルター・詳細・分析・候補は同じ有効値と順位情報を使用。日数不明でアベ比・売上がある場合は暫定判定とし、通常の判定区分による一括追加には含めない。高売上と低アベ比が併存する場合は両方を示す。
- 地図の周辺表示は透明な枠だけだったため、塗り・外枠・番号・機種を持つカードへ変更。全シーンをfitしていた処理を対象ブース外接矩形だけに修正。周辺の切替では倍率・中心を維持する。明示保存済みの非表示設定は保持する。
- 計算結果・カード文字・GraphicsItemを再利用する。現在Excelだけの変更、設定、原価、商品・日付・割当の変更でキャッシュを無効化する。軽量モードは画面描画だけを簡略化し、計算と通常品質のベクター印刷を維持する。

追加検証で、地図のfitをコンテキストなしのsingleShotで予約すると、画面破棄後にコールバックが残り次のQtイベント処理でGIL待ちになる問題を特定した。地図が所有する単発QTimerに変更し、破棄時に予約も取り消す。既存の一括追加・Undo/Redo・画面破棄・次の300台テーマ画面を組み合わせた回帰検証を追加した。

## 検証と制約

- 追加テスト：順位・同額・0・欠損・装飾付き金額・異期間・母集団更新だけの無効化・表示とPDFの一致・暫定候補・300台の項目再利用・軽量設定保存・通常品質PDF・周辺のテーマとfit・A4/A3地図の内容。
- 実画面：人工300ブース／304売上・6照合で、通常／軽量×ライト／ダーク、全フィルター、選択・配置保持、対象だけの地図fitを確認する。WindowsネイティブとポータブルEXEでも同じ検証を実行する。
- 性能は同じ300台・同じ画面サイズ・同じ回数で、変更前84849c4／変更後通常／変更後軽量を測定する。初回と中央値をJSONに保存。読込・照合・初期表示・フィルター・選択・詳細・地図・fit・PDF・画面描画を含む。
- 周辺カードの情報量増加により、初回の地図描画は旧来の透明枠より処理が増える。繰り返し表示は描画キャッシュで軽減する。速度を全項目で一律に保証しない。
- 紙への実出力・実機プリンタードライバー・モニター個別環境の確認は現場で必要。PDF生成、直接印刷の共通描画経路、Windowsネイティブ画面とEXE起動を自動検証する。
