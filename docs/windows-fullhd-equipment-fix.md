# Windows 機器番号照合・フルHD表示の修正

対象ブランチ：`fix/windows-fullhd-equipment-matching`。比較元：`c6ed8b66819248a022df25b48e1cbfdeefcc6a6f`。

## 原因と修正

景品運営分析表の既存リーダーは、既にヘッダー「機器番号」を使っていました。A列の管理番号が空欄・別番号であることを理由に売上を破棄する処理はありません。列順を入れ替え、管理番号に別の機械番号を入れた自動テストでも、機器番号が採用されることを確認しました。

照合不良の主因は、管理番号参考値の番号を**左右付きだけ**に限定していたことです。ユーザー確認により、左右のない16件は1台1ブースの有効な番号でした。参考表の元値を保持し、その本体番号に対応する売上機器番号が一意な場合だけ照合します。左右両方の実績、他ブースとの重複、反対側の実績の読込エラーがある場合は自動照合しません。

Windowsの `-1` / `-2` と一部のハイフンへの未対応も修正しました。正規化はNFKC、空白除去、ハイフン統一を行い、`-01` / `-1` を左、`-02` / `-2` を右とします。本体番号の数字は変更せず、既存の左・右表記も保持します。左右のない参考番号に左右を捏造することはありません。売上の実キーとの対応は照合結果に記録し、参考表を書き換えません。

短い枝番はレイアウトの注記 `11-1` / `11-2` にも存在しました。新しい正規化をそのまま全セル検索へ広げると注記を余分なマシンとして拾うため、短い枝番によるカード検出にはカードの項目構造も要求します。添付4日分の272ブースとその座標・サイズを維持しました。

重複する機器番号ヘッダーは曖昧な列を後勝ちで選ばず、反映前にエラーにします。不正な文字列や空欄の機器番号を持つ実績行も、売上・機器・商品情報がある場合は異常として記録します。既存の同一値重複の一度だけの採用、異なる値の重複除外、日別の重複読込防止を維持しています。

## UIの変更

- 売り場の既存コントロールを共通の折り返しレイアウトに移行。ボタンや既存メニューを維持し、検索欄の横幅を制限しました。
- 詳細パネルの保存・キャンセルをスクロール外に残し、ヘッダー・KPI・フォーム・レーダーを一つの外側スクロール領域へまとめました。独立した多重スクロールによる圧縮を除去しています。
- パネル幅に応じてKPI列数とフォーム／グラフの並びを切り替えます。狭い場合はKPIの次にグラフを配置し、長い編集フォームより先に確認できます。
- ドックの幅変更時に売り場の表示領域を確保し、左右配置と独立ウィンドウを維持。閉じる際も表示中心の復元を予約し、選択・倍率を維持します。
- 読込結果ダイアログを画面内サイズに制限し、サイズ変更・列幅変更・横スクロールに対応。検索は上部、閉じるは下部に維持し、長文はツールチップでも表示します。
- 「matching」などの内部名を日本語分類で表示。エラー・警告・情報は文字と色で区別します。正常照合を警告にせず、元番号・正規化後番号・照合先・状態・理由・対応方法の「照合明細」タブを追加しました。
