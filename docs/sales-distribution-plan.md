# 売上分布・理論PO・候補ページ改善計画

基点: d0d3e3e（前回の検証済み機能を維持）。作業ブランチ: feat/sales-distributions-candidates。

原因: floor_status.filter_status の sales_metric が average を参照し、既定の benchmark の基準額が None のため全台が不明色になる。レーダー・候補・従来分析にも平均売上と固定PO基準が露出している。

1. 売上金額の期間別共通比較を追加。0円と欠損を区別し、同額を同区分に保つ。平均売上は読込・保存・既存アベ比算出の内部処理に保持するが表示・集計から外す。
2. 原価候補・確認原価・正式な単位原価と料金条件を分離して保存。理論PO、許容偏差、取得元・暫定状態を共通計算。集計原価を単位原価として使わない。
3. レーダーの内部正規化を維持し、軸・ツールチップ・表には実数値を表示。売上は同期間の全台順位。
4. 売上分析の入口を6分布の応答型タイルに変更。詳細分析と従来のグラフ・出力を残す。検索・連携は全カードの配置を維持。
5. 入替候補を独立した埋込ページにし、KPI・検索・機種/方法絞込・色・詳細/配置/明示登録・理由付き永続除外を追加。
6. 設定・JSON互換・テーマ・印刷との統合。各段階の集中テスト後、全pytest・実データ確認・Windowsネイティブ/生成EXEの高DPI操作・ZIP Artifactを確認する。

既存テストは削除・無効化しない。依頼で変更された仕様の期待値は根拠を添えて更新し、新しい境界値と実描画検証を追加する。実機プリンターは別途確認が必要。

## 検証経過

- 売上・PO・レーダー共通処理：9テスト成功。
- 分布・候補の300台操作と計算：15テスト成功。
- 全画面の描画用売上境界が保存設定検証へ混入する問題を検出して修正：高DPIを含む13テスト成功。
- 期間別の全台比較、原価確認・料金優先順位、旧設定の移行を追加し、関連38テスト成功。
- 全回帰：468テスト成功後、正式料金の単位・回数欠損の追加2ケースを検証（既存438件を維持＋計32件追加）。既存テストの固定PO・平均売上・画面列数など、依頼により変更した仕様の期待値を更新。テスト削除・スキップなし。
- 添付Excelの298台を照合。売上有効272台は赤58・白146・緑68、売上不明26台のみ灰色。座標・サイズ・商品・設置日・運営方法・元ファイルを保持。
- 合成300台でライト／ダークの6分布、従来11形式、相互連携、候補の埋込・除外復元、CSV／Excel・検索可能な日本語PDFを実描画で検証。
- Windowsでは既存Actionsのネイティブ100/125/150%分析検証と、生成EXEの150%分析検証が拡張済みプローブを実行する。既存の全画面200%・EXE起動・ZIP内容確認も維持する。

## 確認が必要な事項

景品運営分析表のヘッダーだけではP/O率の獲得「個数／回数」や割引条件の定義を確認できない。元のP/O値を保持し、払出数から換算しない。理論POは目安、標準料金は仮設定、商品名末尾は確認前の候補と表示する。実機プリンターの用紙出力は未確認。
