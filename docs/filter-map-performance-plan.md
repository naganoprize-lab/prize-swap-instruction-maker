# 売上順位・評価統合・地図・軽量描画の実装計画

基点：84849c4。ブランチ：feat/ranked-sales-map-performance。既存の指示書印刷本体は維持する。

1. 同一条件の300台で読込・照合・初期描画・フィルター・選択・詳細・地図・フィット・PDFの変更前性能を記録。添付Excelと配置から20111右の実売上と母集団を確認。
2. 売上を現在の売上Excelの有効な全レコード共通順位へ統合。最高黄・次点緑、同額同色・ゼロと欠損を分離。設定色・方式・境界・初期化、凡例と詳細に母集団・順位を表示。
3. 共通評価をカード・分析・詳細・候補で再利用。欠損日数は条件成立とせず、アベ比と売上で暫定判定。高売上併記・不足と判定条件を表示。
4. 地図の周辺は背景色と文字を持つカードへ。対象だけの外接矩形でフィットし、周辺表示の切替で倍率を失わない。画面・A4/A3・一括出力を共通描画へつなぐ。
5. 評価・照合・カード文字のキャッシュと無効化を整理し、不要な全件再生成を抑える。表示状態は計算条件から分離。
6. ノーマル/軽量を永続化。軽量は識別子・分析色・選択枠だけを簡略描画し、計算・操作・印刷品質を維持する。
7. 同条件の変更後計測、追加・既存テスト、実画面比較、Windows全テスト・ネイティブ・ポータブルEXE検証。

根拠：売上は金額分位点を期間/取得元ごとに再計算しており、同一画面に異なる基準が混在し得る。候補は日数欠損で一律保留。地図の周辺はopacity 0.15の枠のみ、fitは周辺を含むscene.itemsBoundingRect。描画はfilter_statusごとに設定検証・PO/原価・候補判定を反復し、sync/更新で重複した再計算を行っている。

母集団の確認結果：ユーザー指定により、添付データでは売上Excel全304台を共通基準とする。レイアウト298ブース中、参考表で確定できる6台以外の実績は基準計算のみに使用し、別ブースへ割り当てない。
