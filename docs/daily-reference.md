# 日別参照・期間集計・タイムラプス

Windows版の既存機能に追加した機能です。入替指示書の帳票本体は変更していません。

## はじめに

1. 設定 →「日別参照データ」で参照フォルダーを選択します。標準名は `入替指示書メーカー_参照値` ですが、任意のフォルダーを使用できます。
2. フォルダーに日ごとの `.xlsx`／`.xlsm` を置きます。一時ファイル `~$...` は除外します。マクロは実行しません。
3. 読込はバックグラウンドで進みます。「自動更新」をONにすると、ファイル追加・変更を検出して再読込します。「今すぐ再読込」でも更新できます。
4. 初回に現在の配置が未登録であれば、最新の確定データに含まれる配置を初期読込します。既存の配置がある場合は、その座標・カードサイズ・永続IDを使用します。

## 対象日と確認

Excel内の明示対象期間を優先します。抽出日時・ファイル更新日時を売上対象日に置き換えません。内部日付の逆転や不一致、別日の同一売上、同期間の異なるファイルを検出した場合は、設定画面の一覧から「日付・区分・採用を確認」を開きます。

日付・単日/期間累計・採用ファイルを確定できます。別日にも全台同一売上が入っている場合は、独立した実績であると確認した場合にだけ専用チェックをONにしてください。原本を修正せず、確認結果をキャッシュに保存します。

添付の11月7日サンプルは、内部の開始日が11月7日・終了日が11月6日で逆転し、304台の売上も11月6日と同一です。自動的に2日分として加算しません。サンプル値は実装に固定していません。

## 表示と編集

ホーム・売り場レイアウト・売上分析・入替候補の期間コントロールは共通です。

- 指定日、直近7日、直近30日、今月、先月、任意期間を選択できます。
- 直近7日/30日は右側の終了日を基準に計算します。取得日のあるカレンダー日を色で示します。
- 「現在の編集データ」へ戻ると、元の編集マスターを表示します。
- 日別参照中は配置を編集しません。現在の指示書・入替予定地図・帳票は現在の物理マスターを参照します。過去データへの切替だけで、現在の商品名や指示書を上書きしません。
- 指定日の詳細で保存した補正は、そのファイル改訂・日付・ブースに限定して保存します。Undo/Redoに対応します。確認済み原価をほかの日へ自動転用しません。
- 期間合計とデータなしの日は参照専用です。

機械番号・参考表による既存の慎重な照合を再利用します。商品名だけで別の台に実績を割り当てません。未照合のExcel実績も全台売上順位の母集団には使用しますが、ほかのブースに割り当てません。

## 集計

- 売上は確定した非重複の実績を合計します。未取得日や欠損項目を0にしません。
- 期間累計は日割りせず、日別実績やほかの累計と重なれば加算しません。
- 原価率は対応する合計原価÷合計売上、P/O率は合計獲得数÷合計実プレイ回数から算出します。複数実績を合算する場合、分母がなければ期間P/O率は未評価です。単一の確定日・確定累計期間にある有効なExcel実測P/O率は原値を保持します。日別率を単純平均しません。
- アベ比は既存の基準アベレージを使います。基準を取得できなければ算出しません。
- 全台順位は同じ選択期間のExcel有効全台が基準です。選択台分析へ切り替えても母集団を勝手に狭めません。
- 取得日数・未取得日数と、項目別の有効データを区別します。機械ごとに取得日数が異なる部分売上を、全期間の順位と混ぜません。

## タイムラプス

売り場レイアウト下部の「タイムラプス」を展開します。範囲、日別/月間トータル、速度を指定して「範囲を設定」から再生します。

先頭・前・再生/一時停止・次・末尾・スライダー、0.5/1/2/4倍、ループに対応します。初期状態ではデータのある日だけ再生し、チェックを外すと欠損日もデータなしとして表示します。停止後も最後の対象日を表示します。

ズーム・スクロール・複数選択・詳細ドックを保持します。詳細を開くと再生を一時停止します。背景の評価色を維持し、変化があったマシンにはオレンジの破線枠を追加します。「変化を強調」で解除できます。同じ日数のフレーム間のみ数値差分を示します。

## 時系列と入替候補

売上分析の「日別・月別の推移」に7種類のタイルを表示します。欠損日の折れ線はつなぎません。棒や区分から当日・該当マシンをレイアウトで強調できます。全台/レイアウト選択中の台の切替は既存の共通選択を使います。

候補の補助情報に、前回取得日、直近売上差、全台順位、アベ比変化、取得日数を表示します。商品・設置日・運営方法が一致しない場合は、売上推移を未評価にします。既存の判定ルールは維持し、「売上低下を優先確認」で同じ判定区分の中を並び替えられます。

## 保存と性能

フォルダー・期間・再生設定は既存JSONに追加し、旧保存ファイルは初期設定で読み込みます。日別実績・ファイル改訂・確認結果・日別補正は、配置の自動保存ファイルに隣接する `.daily.sqlite3` に保存します。別PCへ移す場合は元Excelとこのキャッシュも保管してください。キャッシュの確認・日別補正はJSON単体には含まれません。

SQLiteはスキーマ2で旧スキーマ1を移行します。変更なしファイルはサイズ/mtime、変更候補はハッシュを比較します。日付一覧には軽量索引を使い、集計はバックグラウンド、表示フレームはLRU12件と先読みを使用します。破損した更新ファイルで前回正常データを置き換えません。
