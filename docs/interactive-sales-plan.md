# マシン詳細・売上分析・グラフ連携の実装計画

基点：5db2e97（既存の管理ナンバー照合・テーマ改善を保持）。mainは直接変更せず `feat/interactive-sales-workspace` で開発する。

既存調査：`floor_status` / `machine_matching` が共通の実績・取得元、`method_analysis.period_key` が期間分離、`replacement` が候補判定、`performance_history` が履歴、`analysis_views.show_method_analysis` が現在の独立ダイアログ。`modern_ui` は既存タブを再利用するナビ。詳細編集・Undoは `floor_details` を維持する。

| 段階 | 実装 | 主な検証 |
|---|---|---|
| 1 | 既存調査と本計画 | 保存・テスト・印刷の接点確認 |
| 2 | 共通分析データ・期間別集計・取得元・キャッシュ | 欠損と0、加重平均、期間分離、既存値との一致 |
| 3 | ダークの白系カードと文字・枠 | 49.9/50/99.9/100%、灰との識別、印刷不変 |
| 4 | ヘッダー・KPI・既存編集を保持する可変2カラム詳細 | 旧全項目、スクロール、狭幅、サイズ復元 |
| 5 | 5軸スコア・実測表示・レーダー・設定 | 各境界・補間、未来日、欠損軸、比較対象不足 |
| 6 | メイン内の売上分析ページと既存分析導線 | 別ウィンドウなし、既存タブ番号と状態維持 |
| 7 | 11種類のグラフ・適性制約・ホバー・拡大・保存 | 分布、構成、時系列不足、クリック元UID |
| 8 | 全項目の選択・複合条件・集計・CSV/Excel | 数値範囲、期間、中央値、比率、エクスポート |
| 9 | 双方向連携・独立した分析強調・解除 | 全台表示、座標・サイズ・検索・倍率・選択保持 |
| 10 | テーマ・UI・性能調整、全回帰、Windows EXE | 約300台、DPI100/125/150、PDF、生成EXE起動、ZIP |

追加定義：売上スコアは同じ確定期間・同機種の有効な平均売上について同順位を平均順位として百分位にする。初期比較対象は5台以上（自身を含む、変更可能）、比較対象が全て同値なら50点。期間不明・重大異常・実績と商品文脈が変わった場合は売上スコア／履歴比較を保留する。単一期間から売上推移は推測しない。各履歴の読込時の商品・設置日・運営方法を照合し、重複期間を合算しない。

レーダーは総合点を作らない。欠損軸は欠損として表示し、全軸が揃わなければ閉じた塗りつぶしを描かない。既存のPO基準・原価目標を参照し、POのスコア境界と比較最少台数を設定可能にする。

グラフの集計結果には対象UIDを保持する。通常検索・ダッシュボード強調とは独立した分析強調を追加する。画面投影やテーマ切替で物理座標・サイズを更新しない。CSVの表計算式として解釈され得る文字列は安全な文字列として出力する。

保存は既存形式v3へ省略可能な分析UI状態・詳細サイズを追加し、古いv1〜v3を既定値付きで復元する。既存の自動保存・バックアップを利用。Qtの描画だけを使用し、新しい外部UI依存は増やさない。各段階でテストし、変更点・結果・残件を報告する。
