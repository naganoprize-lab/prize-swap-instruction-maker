# 売上分析・ホーム・複数選択・候補一括追加の改善

作業ブランチ：`feat/home-five-band-analysis`。既存作業 `2f9f89c` を継承し、mainへの直接変更は行っていません。最新mainは `3880a54` であることを確認しました。

## 段階ごとの実装

1. **データの正確性**：売上金額の5段階判定（P20/40/60/80）、0円／欠損の区別、同額の同色化と比較不可表示を共通化。原価候補020/050/1,000、原価の手動修正・取得元、適正PO率、符号付きpt差、実測料金を追加しました。元ExcelのP/O率はユーザー確認に基づき景品獲得数÷プレイ回数として読込み、原値は別に保持します。
2. **マシン詳細**：実数値のレーダーと条件表示、適正PO率との差、共有選択を追加。単独／同額の売上は未評価、PO率100%超の計算値は丸めず警告します。内部座標は0〜100へ制限します。
3. **売上分析**：全体分布・比較分析・詳細データの入口を整理。売上5区分、PO5区分、原価率5区分、10日境界に合わせた投入日数、機種短縮名、タイル順序の保存と拡大を追加しました。比較母集団は同じ期間・取得元の全台を維持します。
4. **ホーム**：4 KPIと8機能タイル、ライト／ダーク、画面幅に応じた配置を追加。入荷予定は既存商品の登録日／稼働予定日を再利用し、実在しない入荷日を補いません。
5. **共通選択**：Machine.uidをキーとするSelectionStateを売り場・分析・詳細・候補で共有。範囲／中心判定、個別、全選択・解除、Ctrlクリック、Shift追加、Ctrl+A、ビューのEsc解除に対応。全画面のEsc解除は既存仕様を維持します。低い画面は選択メニューに集約して描画面積を確保します。
6. **選択台分析**：「全台／レイアウト選択中の台」を追加し、有効／欠損件数を表示。選択だけでは画面遷移しません。ユーザーの全台指定を優先し、レーダーの比較基準は全台のままです。運営方法別の集計にも対象を適用します。
7. **候補の一括追加**：単体、要確認、入替検討、両区分、共有選択を確認画面経由で実際のProductへ追加します。現行商品・現行運営方法・判定理由と、新商品名を分離。機械番号→照合番号→管理ナンバーを自動入力し、両方不明なら空欄です。内部UIDと一意な正規化番号で重複防止、JSON復元、Undo/Redoに対応します。新商品名未設定の下書きは初期出力対象外です。

## 保存と利用上の区別

候補の下書きは既存の一時保存JSONのProductにcandidate_assignmentを追加して保持します。選択台の集合はセッション中の共通状態で、保存した配置・座標・分析色とは分離しています。確定入替日は未設定のまま、現在編集中の日付に下書きを表示します。

過去の原価・料金・集計期間が不明な値を新しい事実として推測しません。異なる期間・取得元を無条件に合算しないため、売上比較の母集団は凡例で示す期間／取得元ごとです。
