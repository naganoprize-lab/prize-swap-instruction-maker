# 管理ナンバー照合・テーマ・モダンUIの変更計画

既存の `Machine.source_key`（管理ナンバー）、`Machine.number`（機械番号）、レイアウト実績と分析オーバーレイ、QGraphicsScene、印刷描画を再利用する。配置・サイズ・検索時の全台表示を維持する。

1. **照合**：番号と管理ナンバーを独立して正規化。対応表を保存し、直接／参考表／手動の矛盾、重複、左右不明を検出する。未照合ではレイアウト実績を使い、各値の取得元を共通サービスで返す。最新の照合済み分析の項目欠損は黙って従来値に補わない。確認・修正用の一覧と旧JSONの移行を追加する。
2. **テーマ**：色トークン・QPalette・スタイルを一元化。システム連動を初期値にし、即時切替・OS変更通知・保存に対応する。画面の分析色をテーマに変換するが印刷色は変更しない。
3. **UI**：既存タブと機能を維持したコンパクトなサイドナビ、ページ見出しと期間・更新日時、テーマ・設定メニュー、カード型ダッシュボード、共通表・メニュー・独自ダイアログのスタイルを追加する。空の画面は作らない。
4. **統合**：詳細、候補、集計、ダッシュボード、印刷が共通照合・数値を使うことを確認する。変更の再計算は既存項目の更新を優先し、旧保存・手動設定・テーマ設定を復元する。
5. **検証**：各段階で対象テストを実行。最後に既存テストを含む全pytest、約300台、全画面、ライト／ダーク、100%・125%・150%（既存200%も維持）のWindowsネイティブ検証、白背景PDF・直接印刷経路、ポータブルEXE起動、ZIP Artifactを確認する。

添付参照Excelは「管理番号参考値」A=管理ナンバー、B=機械番号の6件。298枠すべての実番号が記録されているわけではないため、不足する対応は推測しない。入力Excel・実データを変更・コミットしない。物理プリンターでの用紙出力は自動テストでは確認できない。
