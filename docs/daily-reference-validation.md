# 日別参照・タイムラプス 検証報告

実装基点：92e92b6。実装ブランチ：`feat/daily-reference-timelapse`。Windows検証ブランチ：`feat/daily-reference-windows-ci`。Windows向けアプリのみを変更し、Android向けファイル・外部UIライブラリは追加していません。

## 実装

1. 日付の形式揺れ、Excel内部期間優先、逆転・重複検出、日付/集計区分/採用ファイルの手動確認。
2. 参照フォルダーの登録・自動再走査・変更のみ読込・マクロ非実行・失敗時の前回正常データ保持。
3. SQLiteスキーマ2、旧スキーマ移行、軽量索引、バックグラウンド解析/集計、フレームLRU12件と前後の先読み・停止時キャンセル。
4. 4画面の共通期間選択、非重複期間の合計、取得/未取得日数、分母に基づく原価率/P/O率、既存基準によるアベ比。
5. 現在の編集マスター・物理座標・指示書を保持する表示用履歴モデル。指定日の補正を日別に保存し、Undo/Redoと監査履歴に対応。期間集計は参照専用。
6. 埋め込みタイムラプス。日別/月間、速度・ループ・欠損日、変化枠、ズーム・選択・詳細ドック保持。
7. 時系列7タイル、選択台分析と日付クリック連携、前回取得日・売上差・アベ比変化・順位・取得日数による候補補助情報。

既存の照合・色分け・印刷描画を再利用しています。商品名による機械番号推測や、取得できない日別実績の生成は行いません。

## 添付Excel

両ファイルは304売上実績・298ブース・参考表6組を持ちます。11/06は内部期間11/06〜11/06。11/07は内部開始日11/07、終了日11/06で逆転しており、304台の売上も同一です。

このため、11/06〜11/07を指定したときは取得1日・未取得1日とし、未確認の11/07を加算しません。全台売上の母集団は304台を維持し、20111右は16,100円・31位/304台・上位9.90%・黄色です。298ブースの座標と原本ハッシュの非変更を確認しました。レイアウト由来を含む有効売上は228ブース、機械番号で照合できるのは6ブースです。

実Excelは調査データとしてのみ使用し、Gitコミット・配布用ソースに含めていません。
